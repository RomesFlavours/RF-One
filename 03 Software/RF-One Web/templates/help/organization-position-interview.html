Define / Review Scope with Cognito

A short questionnaire that records, for this Position, where it applies, which Process it owns and which Position backs it up, all in one step. It is a test tool for administrators of the Organization Domain: no AI conducts it, and it is not the final interview experience. Your answers are saved as the same structured data the Position page uses, never as free text.

Questions

Q1. Which Organizational Units (Restaurants) fall under this Position?
Each ticked Restaurant is added to the Position's Scope.
Q2. Which Domain is this Position primarily associated with?
Free text, for example a Domain name. If filled, it is added to the Scope as a Domain, and it is also used as the Domain of the Process in Q3.
Q3. Of which Process is this Position the owner?
If filled, a Process Ownership is created for this Position. If Q2 is empty, the Domain is recorded as UNSPECIFIED.
Q4. Of which Process Phase, if a specific one (optional)?
The phase of that Process; (whole process) means the Position owns all of it. Used only together with Q3.
Q5. Which Position should serve as Backup when this one cannot respond?
If chosen, it is added at the end of this Position's Backup Positions.

Authority and escalation are not asked here: the general last-resort recipient is set in the Organizational Fallback Policy.

Buttons and what happens

Save structured answers
Adds what you answered and returns to the Position's page. Empty answers add nothing. The questionnaire only adds: it never removes or replaces Scope, ownership or Backups already recorded, so answering twice records the same items twice.
