Configuration contains six lists: Menu Type, Menu Area, Category, Components, Supplier and Recipe Type. All sections are collapsed when you first open the page. Select a section row to expand or collapse it.

Recipe Type manages the shared list of recipe types, initially Recipe and Preparation. You can add, rename and archive these values. Managing this list does not automatically change the type of existing recipes.

Add an item

Open its section, enter a name and select Add. For Supplier, also choose the restaurant that the supplier belongs to. Blank names and duplicate names in the same list are refused, including archived names.

Edit an item

Select Edit on its row, change the name and select Save. Cancel restores the saved name. If a value is refused, your entry stays available for correction. Your section and row position are preserved.

Archive an item

Select Archive on its row. The item stays in the list with Archived status; its record is kept. It can still be consulted and its name can be edited. Archive does not delete recipes or change their current classification.

Shared supplier records

Supplier uses the existing Purchasing registry. Creating or editing a supplier here changes that same record for its restaurant. Renaming retains the previous name as an alias. Archiving marks the supplier inactive in Purchasing. A supplier's restaurant cannot be changed here.
