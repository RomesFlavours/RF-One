How Project Management works

Project Management plans projects as a tree of chapters, tasks and subtasks, with dates, durations, responsible people, completion and prerequisites, and shows each project as a Gantt chart that can be printed.

How it works

  • A project contains chapters; a chapter contains tasks; a task can have subtasks (one level only). Codes such as 1, 1.2 and 1.2.1 are given automatically from the order.
  • Each task has a planned start date and a number of planned calendar days: the planned end date is start + planned days − 1.
  • Completion % and actual days are entered by hand. Nothing is rescheduled automatically: when a task starts on or before the planned end of one of its prerequisites, RF-One only shows a warning (⚠).
  • Each project keeps its own list of responsible people: RF-One people or external names.

Typical flow

  1. Click New project and give it a name.
  2. Open the project and create its chapters with New chapter.
  3. Add tasks and subtasks with dates, planned days, responsible and prerequisites.
  4. As the work goes on, update completion % and actual days of each task.
  5. Open the Gantt to see the timeline and warnings, and print it when needed.

What this page shows

Project
The project name; click it to open its plan.
Chapters, Tasks
How many chapters and tasks the project has.
Planned start, Planned end
The earliest planned start and the latest planned end of its tasks (empty when there are no tasks).

Buttons and what happens

New project
Opens a small window asking for the project name. Save creates the project; Cancel or the × closes it without saving.
Open
Opens the project's plan (chapters and tasks).
Gantt
Opens the project's Gantt chart (read only).
Rename
Opens the same window with the current name; Save changes it everywhere.
Responsible (person icon)
Opens the project's list of responsible people. Choose an RF-One person or type an external name under Add a name, then Add. Each name shows how many tasks it has; Rename changes an external name everywhere it is used (a person linked to the RF-One directory is renamed in the directory, not here); Delete asks for confirmation and is refused while the person is still responsible of a task.
Delete
Shown only for a project with no chapters. It asks for confirmation and then deletes the project permanently.

After an action you return to the same row of the list.
