Add Training student

Creates a new RF-One account for a Training student. The account gives access to Training only, with the student role, and the password set here is the student's real RF-One sign-in password.

Fields

Username
The name the student will use to sign in. It must not already be in use.
Display name
The student's name as shown in RF-One and Training.
Email
Required. RF-One e-mails a verification code to this address; the student confirms it from their own Profile page.
Password / Confirm password
The student's sign-in password, typed twice. If the two entries differ, nothing is created.

Buttons and what happens

Create student
Creates the RF-One account and the Training student, and sends the verification e-mail. The student can sign in to RF-One straight away. You are then taken back to the RF-One Home. If something is refused (for example an e-mail already in use), the reason is shown and nothing is created.

Next steps

Give the student their username and password. The student then appears in the Students list, where you can reset the password if needed.
