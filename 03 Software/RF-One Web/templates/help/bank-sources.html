Source

The list of every Source RF-One expects financial data from: bank accounts, credit cards, PayPal and purchase platforms. Active Sources are the ones Import and Review expects in every imported period; inactive ones are kept for history. This is the only place where Sources are created and edited.

Fields and columns

Source, Type, Institution / Provider
The name used everywhere in Bank, the kind of Source and the bank or provider.
Account
Only the last four digits; the full number is never shown.
Owning entity
The company or person that owns the Source; the Monthly Export makes one report per owner. A card's owner is not chosen: it comes from its settlement account. A purchase platform is a documentary source (orders and receipts) and its owner is optional.
Settlement / Funding
For a card, the bank account that pays it and the cardholder; for PayPal, the bank account that funds it.
State
Active or Inactive.

Buttons and what happens

+ New Source / Edit
Open the Source window. Fields: Source name, Type, Institution / Provider, Last 4 digits (used to recognise card files), Account identifier as written in the file (never the full number; on Edit it starts empty and the stored value is kept unless you type a new one), Owning entity (not for cards), Currency, Funded by (PayPal only). For a card: Settlement / Funding account and Cardholder, each with a “from” date; a change starts on that date and the previous period is kept. On Edit you also see State and the Card history, where Correct fixes a period recorded wrongly. Save saves the Source and reloads the list; an error stays in the window with your values. Cancel or × close without saving.
+ New Entity
Inside the Source window: creates a company / LLC or a personal entity by name (or reuses an equal active one) and selects it as owner. The Source itself is saved only by its own Save.

Below the list

File recognition rules
A person's choice of Source for a file that cannot identify its own account, reused on the next import. Choose another Source and Save, or Disable / Enable the rule; disabling never deletes it.
Source assignment history
The last changes of Source made on imported files: when, from which Source to which, how many rows, by whom and why. Read only.
Accounting deduplication
Counters of raw rows, canonical transactions, duplicate groups, copies excluded from accounting and card transactions with no settlement account. Recompute accounting deduplication recalculates them for all transactions, for example after setting a card's settlement account; no row is deleted.
