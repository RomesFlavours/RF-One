New work

This page creates a new card in the Development Journal: one change with a verifiable result. After saving, the card opens and you can start adding entries and documents.

{% else %}

Edit work

This page changes the card of an existing work: its description, responsible person, phase, status and next step.

{% endif %}

Fields

Title
Required, up to 200 characters. A short name that says what the work changes.
RF-One Domain concerned
Required. The area of RF-One the work is about.
Responsible
Required. The person who leads the work. Only people with access to the Development Journal can be chosen; a person who no longer has access stays on the works already assigned to them, marked “(no longer enabled)”.
Phase
Where the work is: Study, Specification, Development, Local test, Ready for release, Released.
Status
In progress, Waiting, Blocked, Completed or Cancelled. Completed and Cancelled close the work; it can be reopened from the card.
Objective
Required. The problem to solve and the expected result.
Next step
Optional. What has to be done now, and by whom. It is shown on the list and at the top of the card.

Buttons and what happens

{% if mode is defined and mode == "create" %}
Create work
Saves the new card with you as its author and opens it. If a required field is missing, nothing is saved and the page shows the reason with what you typed.
Cancel
Returns to the list without saving.
{% else %}
Save
Saves the changes and returns to the card. A change of phase or status is recorded in the card's history, with your name and the time. If a required field is missing, nothing is saved and the page shows the reason with what you typed.
Cancel
Returns to the card without saving.
{% endif %}

Next steps

On the card, add entries to document the work and attach documents. Author, creation time and last update are recorded automatically.
