Students

The list of Training students: people whose RF-One account gives access to Training only, as students. Trainers use it to add students and to set a new password for a student who cannot sign in. This page is available to people who hold the Training trainer role.

Columns

Display name
The student's name.
Username
The name the student uses to sign in to RF-One.
Reset password
A new password, typed twice (New password and Confirm).

Buttons and what happens

+ Add Training student
Opens the form to create a new student account.
Reset
Replaces that student's RF-One password immediately with the one typed. The old password stops working. If the two entries differ, nothing is changed. Tell the student the new password yourself: RF-One does not send it.
