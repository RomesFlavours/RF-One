Availability

Find or edit a wine in the purchasing catalog. Use Search to filter by type, producer, label or supplier; New wine opens the creation form and Edit opens the selected wine.

Wine Types and Availability

Wine Types stores a standard name and alternative names. Names already assigned to another type are refused.

Availability is the purchasing catalog, not an inventory count. A wine records its type, producer, label, vintage or non-vintage status, category, style, denomination, region, bottle size, supplier, cost, cost date and notes. Availability can be Available, Incoming or Not available.

Search the catalog to find an existing wine before adding one. Duplicate wine identities are rejected. An unknown cost can stay blank; it is never silently treated as zero.

Enter a four-digit vintage between 1900 and 2100, or select Non-vintage to clear and disable the year. Save validates and stores the wine; Cancel or the close button discards unsaved changes. Upload file is currently unavailable.
