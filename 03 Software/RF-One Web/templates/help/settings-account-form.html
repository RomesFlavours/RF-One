Use this form to create a new RF-One account, so a person can sign in to RF-One. Only RF-One administrators can open it.

{% else %}

Use this page to change an existing account's display name, status and administrator role, and to give it a new password. Only RF-One administrators can open it.

Fields

{% if creating %}
Username
The name the person will type to sign in. It is saved in lower case, must not already be used by another account, and cannot be changed later.
{% else %}
Username
Shown for reference only: a username cannot be changed.
{% endif %}
Display name
The name shown for the person inside RF-One. Required.
{% if creating %}
Email
Required. It must not belong to another account. A verification code is emailed to this address; the person confirms it from their own Profile page. The account can sign in even before the email is confirmed, but self-service password recovery works only with a confirmed email.
Password / Confirm password
The first password of the account. The two must match. Give the password to the person through a safe channel.
{% endif %}
Status
Active lets the account sign in; Inactive refuses its sign-in without deleting anything. The owner of RF-One is always Active, so the choice is locked for that account.
RF-One administrator
An administrator manages accounts and settings, and administers every Domain the account is given access to. Being an administrator does not by itself open any Domain: Domains are still granted in Domain Access. To let someone administer only some Domains, leave this unticked and give the role "Domain administrator" in Domain Access instead.

Rules that protect the administrators

  • The owner of RF-One always stays an active administrator.
  • You cannot remove your own administrator role or deactivate yourself; another administrator can.
  • A change that would leave RF-One without any active administrator is refused.

When a rule blocks a change, the page shows the reason and nothing is saved.

Buttons and what happens

{% if creating %}
Create account
Creates the account and emails the verification code to the address entered, then returns to the Accounts list. If something is wrong (for example the username or email is already used, or the passwords do not match) the account is not created and the reason is shown.
{% else %}
Save changes
Saves the display name, status and administrator role, then returns to the Accounts list. You can change them again at any time.
Reset password
In the Reset password box: type the new password twice and press the button. The old password stops working immediately and cannot be recovered, and every session where the person is signed in is ended, so they must sign in again with the new password. This does not save the other fields of the form.
{% endif %}
