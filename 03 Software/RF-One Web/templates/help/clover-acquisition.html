How Clover Acquisition works

Clover Acquisition brings the restaurant's Clover data (Orders, Payments, Tips, Gratuity and Shifts) into RF-One, so that Tips, Compensation and the other areas work on up-to-date figures. It only reads from Clover: nothing is ever written back to Clover.

How it works

  • Each acquisition reads one period of Clover data for the Clover Location of this Restaurant and updates what RF-One already holds. Reading the same period again updates the records with Clover's current values; nothing is duplicated.
  • Only one acquisition at a time can run for a Location. It runs on its own: you can leave the page while it works.
  • Every acquisition you start is recorded as requested by you, the signed-in person.
  • A Correction Sync runs automatically about every minute and re-reads what was modified in Clover after it was first acquired.

Typical flow

  1. The first time, run a Historical Backfill for the period you need: it also sets the starting point for Sync Now.
  2. Afterwards, press Sync Now whenever you need RF-One up to date. It reads from the last completed synchronization up to now.
  3. Watch Acquisition in progress; the page refreshes itself when the acquisition ends.
  4. Check the result in Acquisition history.

What this page shows

Acquisition in progress
The acquisition currently queued or running, its type, period and who requested it. While it is shown, the Sync Now and Run Historical Backfill buttons are disabled.
Last completed synchronization
Where the next Sync Now will start. When there has been no synchronization yet it starts from the end of the latest Historical Backfill; "none yet" means a Historical Backfill is needed first.
Live Sync
Whether continuous automatic synchronization is ACTIVE, ENABLED, NOT RUNNING or NOT ACTIVE. When it is not active, RF-One is updated only by Sync Now and Historical Backfill.
Acquisition history
The recent acquisitions: number, type, who requested it ("System (automatic)" for automatic ones), status (COMPLETE, PARTIAL means completed with warnings, FAILED; "no sign of life" means the job stopped responding), the period read, start and end, the Orders, Payments and Shifts processed and any errors. A "-" count means the acquisition was recorded before counts were tracked.

All times are the Location's local time.

Buttons and what happens

Sync Now
Starts an acquisition from the last completed synchronization up to now. No dates to choose. Disabled while another acquisition is running, when no Clover Location is configured, or before the first Historical Backfill.
Run Historical Backfill
Reads one specific historical period, given as whole local days from 00:00 of the From date through 23:59 of the Through date. Use it for a first load, a known gap or a correction; it is not the everyday way to update RF-One. The Through date cannot be before the From date.

An acquisition cannot be cancelled from this page once it has started.
