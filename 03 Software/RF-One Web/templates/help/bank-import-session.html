Import session

The files you uploaded on Import and Review, prepared in two passes before anything is imported. Nothing becomes a bank movement until Confirm Import; Pass 1 only creates or reuses Sources. The session belongs to the person who uploaded the files.

Pass 1 — Sources

Each file gets its Source. The account comes from the file name (a suffix such as “(1)” is ignored) and the layout from its content; a name matching exactly one Source gets it.

Columns
File, Layout, Account (name) (digits read from the name), Source (existing, or created in this session), Source status (complete, incomplete with what is missing, to choose when several Sources match, or not set) and Importer (whether this import can read the file).
Complete Source
Opens the Source window for that file: in Source of this file keep the current Source, choose an existing one or create one from what the file states, and complete its fields (name, type, institution, last 4 digits, owner, currency; for a card its settlement account and cardholder). Save saves the Source and links it to the file, and you come back to the same row. Cancel changes nothing.

Pass 2 — Read and check

Read and check rows
Available when every Source of the files being imported is complete. It reads every row without saving it: rows per file, period, identifiers found inside the file (kept as original data only), copies of the same content and files already imported. Press it again after a change.
Files that cannot be imported now
A file with no importer yet, or with an unknown layout, is never left out automatically: choose Confirm: leave out of this upload for each one. A file with no importer yet is kept for a later import.
Warnings — expected Sources missing
Active Sources with no file for a month covered: shown, not blocking.
Possible duplicates and unreadable rows
A possible duplicate is a row with the same date, description and amount as a stored transaction or another row of this upload. For each row choose Confirm exclusion, Import, marked Da verificare (the default: it is imported and flagged in Review) or Import anyway: distinct operation. The buttons above a file's rows set the same decision for all its possible duplicates. An unreadable row can only be excluded. Each decision is saved as soon as you choose it and can be changed until Confirm Import.

Buttons and what happens

Confirm Import
Available when both passes are complete and every row and file has its decision; otherwise the reason is shown above it. It imports every readable file with its Source and your decisions, all together or nothing. Then you return to Import and Review, with a message per file. Files left out for a later importer are kept aside, not imported.
Cancel import
Discards the uploaded set. Nothing had been imported, so there is nothing to undo; Sources already saved in Pass 1 stay. To start again, upload the files again.
