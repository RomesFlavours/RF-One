Correct entry

This page corrects an entry already written in a work's journal. A correction never erases the past: the text being replaced is kept as an earlier version, with its author and date, and stays available from the entry.

Fields

Reference phase
The phase of the work the entry belongs to. Changing it does not change the phase of the work.
Type
Analysis, Decision, Activity, Verification, Problem or Release.
Text
Required. The corrected text.
Release
Shown only for the Release type: Environment, AWS service, Version or commit and Outcome are required; Post-deploy verification is optional.
References (optional)
Link (starting with https:// or http://), branch, commit, command or prompt.

Documents are not changed here: documents already attached to the entry stay attached. To add one, use “Attach documents to this entry” on the card.

Buttons and what happens

Save correction
Saves the new text as the next version of the entry and returns to it on the card. If nothing was changed, no new version is created. If a required field is missing, nothing is saved and the page shows the reason.
Cancel
Returns to the entry on the card without saving.

Next steps

On the card the entry now shows “corrected” with its version number; click it to see every version.
