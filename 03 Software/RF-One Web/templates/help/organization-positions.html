Positions

A Position is a stable responsibility in the company (for example a manager role), independent of the person who occupies it. This page lists every Position with the Position it reports to and its current occupant. It is a configuration and inspection page, not the place where people receive their requests.

What you can do

  • See all Positions, which are active, and which are vacant.
  • Open a Position to see{% if org_may_administer() %} and change{% endif %} its Scope, occupants, Temporary Coverage, Backup Positions and the Processes it owns.
    • {% if org_may_administer() %}
  • Create a new Position.
    • {% endif %}

Fields and columns

Name
The Position's name.
Parent
The Position it reports to; "-" for a top-level Position.
Active
Whether the Position is active or inactive.
Current Occupant
Who occupies the Position now. VACANT means nobody does; it is a normal state, but requests owned by a vacant Position need a Temporary Coverage, a Backup Position or the Fallback Policy to reach someone.
