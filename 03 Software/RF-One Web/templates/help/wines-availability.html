Availability

This page is the catalog of the wines that can be bought: for each wine, its supplier, cost and availability. It is the source from which wines are added to a Wine list. It is not a count of the stock on hand.

What you can do

  • Search the catalog by type, producer, label or supplier, before adding a wine, to avoid duplicates.
  • Add a new wine, or change an existing one.

Columns

Type · Label
Wine type and label name, with denomination and region when recorded.
Producer, Vintage, Category, Format
Producer, vintage year (or non-vintage), category and style, and bottle size in ml.
Supplier
Who the wine is bought from.
Cost
Cost per bottle in USD, with the date of the cost. “Cost unknown” means it has not been entered; it is never treated as zero.
Availability
Available, Incoming or Not available.

Buttons and what happens

Search / Clear
Show only the matching wines, or all of them again. They change no data.
Upload file
Not available yet: loading the catalog from a file is waiting for a sample file.
New wine / Edit
Open the wine window (below). Save wine stores it and reloads the list; Cancel or the × closes the window without saving. If something is refused, the window stays open with what you typed and the reason.

The wine window

Wine type
Required. Type to search the existing types (alternative names are recognized). The + button opens the New wine type window on top, without losing what you typed; the new type is then selected.
Producer
Required.
Label name
Optional.
Vintage / Non-vintage
A year is required, unless you tick Non-vintage.
Category, Style
Required: Red, White or Rosé; Still, Frizzante or Sparkling.
Denomination, Region
Optional.
Bottle format (ml)
750 unless you change it.
Supplier
Optional; suppliers already used are suggested.
Cost per bottle (USD)
Leave it empty if it is not known yet. When you enter a cost, the cost date is set to today if empty.
Cost date, Availability, Notes
When the cost was valid, whether the wine can be bought, and free notes.

The same wine cannot be entered twice: if type, producer, label, vintage and format match a wine already in the catalog, the save is refused and you are asked to edit that one instead. Changing a cost here does not change prices already on a Wine list: the Wine List shows the new cost and lets you adopt it row by row. Wines cannot be deleted from the catalog on this page.
