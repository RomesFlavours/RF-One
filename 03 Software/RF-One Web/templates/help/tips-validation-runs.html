Tips — saved periods

Lists every saved Tips Calculation Run of each Restaurant, final and not, so that an authorized person can open a period and validate it. Tips are calculated in the Tips app; this page only shows the saved results and leads to their validation.

Columns

Tips Validation Mode
How the Restaurant's periods become final, as configured for that Restaurant.
Run
The number of the saved Calculation Run.
Business Dates
The first and last Business Date the run covers.
State
FINAL means the period is validated, cannot change and is payable. Any other state (for example CALCULATED) is shown as "not payable".
Control difference
Total Tips + Gratuity minus the total owed to employees. It must be $0.00 for the period to be validated.

Buttons and what happens

Open
Opens the saved report of that run, where it can be validated. Opening it changes nothing.

Next steps

Open a period that is not yet FINAL, check its control and the amounts per employee, and validate it if the figures are right.
