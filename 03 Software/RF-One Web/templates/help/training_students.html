Students

Invite student offers confirmed Selection candidates or a direct invitation, both using one activation page. The recipient chooses a password if new or proves the current RF-One password if already registered. Existing Registry identities are reused after explicit confirmation; no employee is created. The full manual-entry workflow below remains under New student.

Select New student and enter first name, surname, email and optional phone. RF-One checks existing people and logins; possible matches require explicit confirmation. Never link different people merely because names match. New students receive a central Registry identity and STUDENT qualification, not an employee record or other module permissions. Existing confirmed logins retain credentials and permissions.

A new username combines first name and the first three surname letters, for example MarioRos. Collisions receive a number. The system emails a random initial password and a personal activation link, valid once for 48 hours. The link alone does not sign in: the student supplies initial credentials and chooses a different personal password before opening MyRF.

If delivery fails, the account remains saved. Resend invitation issues a new initial password and link for a never-activated account and invalidates the old ones. Existing verified accounts receive a sign-in invitation; unverified existing accounts use the six-digit activation code. Resends are limited to one per minute and five per hour.

Manage student

Manage opens details in a dialog. Save student saves changes; Cancel or × closes without saving. Leave password fields blank to preserve credentials. A new password requires replacement at first sign-in. Credentials for administrators and accounts with access to other modules are managed by RF-One administrators.

Archive blocks Training and removes the student from new assignments, preserving identity, assignments and results. Other legitimate module access is retained. Open Archive, then Manage and Restore student to restore Training access. Old sessions are revoked. The ? button opens this explanation without losing the draft.

Assign content

Select Assign content on the student row. The recipient is fixed. Select available content and Confirm assignment to save its published version. Draft and withdrawn content is excluded. Archived or inactive students cannot receive assignments. Errors preserve selections; Cancel or × closes without assigning. After saving, the list returns to the same row and search. Refresh does not repeat submission. A new confirmation creates another learning path.
