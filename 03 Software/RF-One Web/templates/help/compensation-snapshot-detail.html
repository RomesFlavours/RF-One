Approved Compensation Snapshot

The approved, unchangeable figures of a compensation run. From here you hand the figures to the Payroll Provider, record that you did so, and record the Provider's result so RF-One can compare it with what was approved.

Sections of the page

Manual export view
One row per approved Employee with the Provider ID (MISSING when the Employee is not yet mapped to the Payroll Provider), Regular Hours, Regular Pay, Tips, Recognized Incentive, Tip Credit Make-Up, Bonus and Gross Pay, ready to be transcribed into the Payroll Provider.
Communication to the Payroll Provider
Every communication recorded so far: who, when, reference and note.
Payroll Provider result & reconciliation
Every Provider result already recorded, each with its reconciliation (View), and the form to record a new one.

Buttons and what happens

Download CSV
Downloads the export rows as a CSV file. Nothing is changed or sent.
Confirm communication
Records that you handed the approved figures to the Payroll Provider, with the date (today if left empty), a reference such as the Provider's batch number, and a note. The first confirmation moves the run to EXPORTED. It does not mean payroll was processed or paid. A recorded confirmation cannot be removed from this page.
Record result and reconcile
Records what the Payroll Provider reported: the Restaurant, the source system, the run type (Regular or Special), the period, the Pay date (required), an optional Provider reference, and per Employee the Regular Pay, Tips, Bonus/Incentive and one other labelled amount. Leave blank what the Provider did not report; at least one value is required. RF-One then compares the matching components with the approved figures and opens the new reconciliation. It never compares the Provider's net pay with a compensation total. The same result (same source system, Restaurant, period, pay date and run type) cannot be recorded twice.

When no Restaurant is on file for this Legal Entity, or no source system exists, the result form is not shown.
