Calculation Run

The saved report of one Tips period, read back exactly as it was calculated (this page never recalculates), and the place where a person validates the period so that it becomes FINAL and payable.

What the page shows

Header
The Restaurant, the Business Dates, when the operating day starts and in which timezone, the Rule Versions applied, and when the run was calculated.
The control
Voluntary Tips, Gratuity, their Total Tips + Gratuity, the Total Employee Entitlements and the Control Difference between them. "balanced" means the difference is zero; "does not balance" means money is unaccounted for. The difference is reported, never adjusted.
What each employee is owed
Per employee: the Result type, the Gross amount and the Final Entitlement. If the rows do not add up to the total recorded for the run, a warning tells you not to validate or pay the run until it is explained.
Validation and finalization
For a FINAL run: when it was finalized and by whom, or that it was finalized automatically under the Restaurant's validation mode. For a run not yet final: every reason that prevents validation, or the validation button.

Buttons and what happens

Validate this period as …
Records you, the signed-in person, as the validator and makes the period FINAL. A FINAL period can no longer be modified and is the Tips figure Payroll may use for those dates. This cannot be undone. There is no name to type: the validator is always who is signed in.
{% else %}

Why validation is not possible

The red messages list every reason at once, for example: the calculation did not complete, the period does not balance, another run is already FINAL for the same Business Dates, or an employee identity still has to be confirmed. Resolve the cause (in the Tips app, or by confirming the identity in the employee directory) and come back: the period can be validated only when no reason is left.
