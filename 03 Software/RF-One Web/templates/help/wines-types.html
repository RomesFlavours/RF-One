Wine Types

This page is the register of wine types (for example a grape or a style name). Each type has one standard name and, optionally, alternative names, so that the same type is recognized consistently when wines are added to the catalog.

What you can do

  • Search a type by its standard name or by one of its alternative names.
  • Create a new type or change an existing one.

Columns

Standard name
The name used everywhere in Wines.
Alternative names
Other names of the same type (for example Pinot Gris for Pinot Grigio); typing one of them in the catalog finds this type.
Wines
How many catalog wines use this type.

Buttons and what happens

New wine type / Edit
Open the type window: Standard name (required) and Alternative names (optional, one per line). Save type stores it and reloads the list; Cancel or the × closes the window without saving.

A name already used by another type, as a standard or alternative name, is refused, so the same type cannot be created twice under different names. Changing a standard name changes it everywhere the type is used. Types cannot be deleted on this page.
