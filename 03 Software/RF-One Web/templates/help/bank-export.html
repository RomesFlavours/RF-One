Monthly Accountant Export

Produces the accountant's Excel report for one month and one Owning Entity (a company or a person). The report holds only the movements of that owner's Sources (a card counts for the owner of the account it settles to) and can be downloaded only when nothing blocks it. For Whom is kept as it is.

What you can do

  1. Enter Year and Month, choose the Owning Entity and press Check. Nothing is changed by a check.
  2. Read the status: ready, not ready, or no transactions for this owner and month.
  3. If it is not ready, fix what is listed under What blocks the export, then press Check again.
  4. When it is ready, press Download to receive the file.

Figures

Sources unresolved
Files or Sources whose transactions have no accounting identity yet.
Transactions to reconcile
Transactions still on the To Reconcile tab (WHO not answered, or a possible duplicate to decide).
Reconciled, Needs review
WHO answered, but WHY, For Whom or the Confirm is still missing.
Confirmed
Transactions accepted by a person.
Transactions in month, Rows in the file, Total
What the report would contain, with the total per currency.

What blocks the export

A. Source issues
A file with no Source, a file with parsing errors, a card with no settlement account or an account with no owner. Fix Sources and Fix this file open the file on Import and Review; Open Source opens the Source to complete it.
B. Transactions to reconcile
Review Transactions opens the To Reconcile tab for the month.
C. Reconciled but not ready
Review Reconciled opens the Reconciled tab for the month.
D. Other export blockers
Accepted transactions whose WHO / WHY / WHAT record is incomplete.
Show N transactions
Lists the transactions of a group with the reason each one blocks; Open goes to that transaction in Review, Hide closes the list.
Not attributed to any owner
Movements of Sources with no owner: they are in no report until their Source has an owner, and they do not block this report.

Buttons and what happens

Check
Recalculates the status for the chosen month and owner. Read only.
Download
Checks the blockers again and, if none remains, downloads the file named with year, month and owner. Downloading changes nothing in the Bank data and can be repeated.
