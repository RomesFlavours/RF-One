Menu manages named menus for a location. Open a menu to see its dishes grouped by Menu Area. Entries connected to an existing Kitchen recipe are dishes; entries without a recipe are text labels. Recipes and their photos remain in Kitchen and are not copied into a menu.

Create or edit a menu

Select New menu or Edit. Enter a name and choose the Restaurant location. If there is only one location, it is assigned automatically and is not shown. Add entry creates a row: choose a shared Area, enter its label and optionally choose a dish recipe. Choosing a recipe fills a blank label with the recipe name. Preparations cannot be selected as dishes. Use Configuration to create Menu Areas. Areas are common to all restaurant locations. The recipe dropdown contains only dishes whose Category matches the selected Area name, ignoring letter case and extra spaces. Without an Area, no dish recipes are offered. Recipes without a Category are not offered.

Entries appear under their Area in the order entered. Up and Down change their order; Remove removes an entry from the draft. Changing restaurant location keeps Area and recipe selections. Changing an Area clears a recipe that no longer matches, leaving the entry as a label. An existing saved recipe with a mismatching Category must be replaced or explicitly changed to Label only before saving. Existing archived Areas may be retained on their existing entries but cannot be assigned to new entries.

Save menu applies all changes together. Invalid recipes, recipes from a different Category and stale changes are refused without closing the draft. Cancel, × or Escape discards unsaved changes. The ? button opens this help while preserving the draft. Closing a dialog returns to the same menu and page position.

Archive

When you change a recipe, its label follows the new recipe name if it was blank or still matched the previous recipe name. A custom label is preserved. The recipe dropdown is filtered by the selected Area's matching Category; a dish with a different name may still belong to that same Category.

New menus start as Draft. Select Activate to make a menu the active menu for its restaurant location. The previous active menu at that same location returns to Draft automatically in the same operation. Other locations are unaffected. Only one menu per location can be active, including when two operators activate menus at the same time. An archived menu cannot be activated.

Editing an active menu keeps it active unless you change its restaurant location: moving it makes it a Draft without replacing the destination's active menu. Archiving the active menu leaves that location without an active menu until another is activated. No replacement is chosen automatically.

Archive retains the menu and all its entries as read-only history. Archived menus stay visible and can be opened for consultation. Archiving does not change or archive their Kitchen recipes or Menu Areas.
