Entry versions

This page shows every version of one journal entry, newest first, so you can see what was written originally and how it was corrected. It is read only.

What you see

Version N · current
The text in force today, with the time and the person who wrote this version.
Version N
An earlier version: who wrote it and when (“written”), and when a correction replaced it (“replaced”).
Type and phase
The entry type and the reference phase of each version; both can change in a correction.

Times are in the local time indicated at the top of the page. If the entry has never been corrected, only the current version is listed.

Buttons and what happens

Back to the card
Returns to this entry on the work's card. Nothing on this page changes any data.
