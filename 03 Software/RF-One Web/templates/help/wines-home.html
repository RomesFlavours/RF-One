How Wines works

Wines builds a reliable catalog of the wines the restaurant can buy, prepares a dated Wine list for each Entity, and calculates and controls its selling prices.

How it works

  • Wine Types keeps one standard name per type, with alternative names, so the same type is always recognized in the same way.
  • Availability is the purchasing catalog: each wine with its supplier, cost and availability. It is not a stock count.
  • Wine List keeps, for each Entity, dated versions of the list. The effective date decides whether a version is In effect, Prepared (future) or Previous. A prepared version leaves today's list in effect until its date; previous versions can be consulted and exported but not changed. Dates follow the restaurant Location's time zone.
  • Prices are calculated from the cost and a commercial Value that you assign, and you can set them by hand. A later change of catalog cost or of the pricing parameters is flagged on the list; prices already on a list never change by themselves.
  • You supply and approve suppliers, availability, costs, Values, prices and dates. Wines does not use a generative AI model, research suppliers, place orders, track stock or publish recommendations by itself.

Typical flow

  1. Define the Wine Types you need.
  2. Record the wines you can buy in Availability, with supplier and cost.
  3. On this page, choose the Entity.
  4. Click New Wine list: choose the effective date and start empty or from a copy of the list in effect.
  5. Add wines with Add new wine to current Wine list, set their Value and whether they are sold by the glass, and review the prices.
  6. Check the prices marked “To complete” and the change warnings, then Export Wine list.

What this page shows

Entity
The business whose Wine list you see. Entities come from the Legal Entities registry. Changing it reloads the page.
Versions
Every Wine list version of the Entity, with its effective date and state. Click one to show it; the page opens on the version in effect (or, if none is in effect yet, the nearest prepared one).
Cost used
The cost per bottle the prices are based on. “Catalog now $…” means the catalog cost changed after the wine was added.
Value
Your commercial assessment of the wine (not an AI rating). A higher Value gives a higher price.
Bottle price, Glass price
The prices applied on the list. “To complete” means there is no price yet (for example, the cost is unknown or not above $1). “Set by hand · calculated …” shows a price entered by hand next to the calculated one. “Calculated with earlier parameters” means the pricing parameters changed since the price was calculated. The glass price applies only to wines sold by the glass.

Buttons and what happens

New Wine list
Opens a window: Effective from (required), then Empty list or Copy of the current list (available only when a list is in effect today; it copies wines, costs used, Values, parameters and prices). Create Wine list creates the version; an Entity cannot have two versions with the same date. Earlier versions are kept.
Add new wine to current Wine list
Available only on a version in effect or prepared. Opens a window to pick a wine from the catalog (wines already on the list cannot be picked), then Cost used, Value and Sold by the glass. The calculated prices appear as you type; the applied price follows the calculated one until you change it, and then it counts as set by hand. Add to Wine list saves the row.
Edit
Opens the same window for that row; Save stores the changes.
Restore calculated
Replaces the prices set by hand with the calculated ones, immediately.
Adopt and recalculate
Takes the new catalog cost for that row and recalculates its prices.
Adopt parameters
Recalculates that row with the current pricing parameters.
Delete
Asks for confirmation, then removes the wine from this Wine list. It stays in the catalog.
Export Wine list
Downloads the shown version as a CSV file (Entity, date, category, type, label, producer, vintage, format, bottle and glass price). Nothing is changed.
Pricing parameters
With cost C and Value V, the bottle price is C × A ÷ logB(C) × V², and the glass price is that unrounded amount ÷ G; each price is rounded separately to the whole dollar, halves up. A cost of $1 or less, or an unknown cost, gives no calculated price. Save parameters applies to prices calculated from now on, for every Entity; rows already on a Wine list keep their prices until you use Adopt parameters on them.

Edit, Restore calculated, the Adopt buttons and Delete appear only on a version in effect or prepared; a previous version can only be consulted and exported.
