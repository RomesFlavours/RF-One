Le tue credenziali personali

Puoi conservare il nome utente oppure sceglierne un altro disponibile. Inserisci e conferma una password di almeno 8 caratteri, diversa dalla password iniziale. «Salva e continua» registra le credenziali e apre Training. La password iniziale non funziona più e le precedenti sessioni vengono invalidate. «Esci» termina l’accesso senza modificare le credenziali.
