New compensation preparation run

Creates a preparation run for one Legal Entity and one period. The run is where hours are shown and pay is calculated for each Employee before approval.

Fields

Legal Entity
The employer whose Employees are paid. Only active Legal Entities are listed; the run includes the Shifts worked at the Locations of this Legal Entity.
Period start / Period end
The first and last day of the pay period. The end cannot be before the start.

Buttons and what happens

Create run
Saves a new run with status OPEN and opens it. Nothing is calculated, approved or sent at this point. A run that is still OPEN or CALCULATED can be worked on freely; it becomes fixed only when it is approved.

Next steps

In the run, check the hours of each Employee, add Incentive Contributions if needed, calculate each Employee, then mark the run as Calculated and approve it.
