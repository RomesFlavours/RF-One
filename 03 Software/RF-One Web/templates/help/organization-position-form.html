New Position

Use this form to create a Position: a stable responsibility in the company, independent of the person who will occupy it. Only administrators of the Organization Domain can open it.

Fields

Name
The Position's name, for example the name of a role. Required.
Description
Optional text explaining the responsibility. It is shown under the Position's name on its page.
Parent Position
The Position this one reports to. It decides where the Position appears in the Organization Chart. Choose (none) for a top-level Position.

Buttons and what happens

Create Position
Creates the Position, active and vacant, and returns to the list of Positions. If the name is empty, nothing is saved and the reason is shown. The name, description and parent cannot be changed afterwards from these pages, so check them before creating.

Next steps

Open the new Position with Manage in the list to set its Scope, assign its occupant and add Backup Positions, then record the Processes it owns in Process Ownerships.
