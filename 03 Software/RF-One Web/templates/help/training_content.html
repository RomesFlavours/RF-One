Course catalog

Prepare courses, search by title or objective, and review status and version. Only available courses can be assigned. Withdrawn items are not shown; historical assignments are retained. The course title opens its content or draft preview. Visual Menu reuses its existing RF-One page rather than separate courses for individual dishes.

Create or edit a course

Choose New course and enter its title, description and objective. Add lessons in the intended order. Each lesson can contain text, an RF-One page, an HTTPS link, a PDF or an MP4/WebM video. For an RF-One page use an internal path such as /training/visual-menu. The up/down buttons reorder lessons; × removes a lesson from the draft.

Save draft retains incomplete work and requires a title. Make available also requires a description, objective and at least one complete lesson, then automatically creates the next assignable version. Manage reopens the form. Draft edits do not replace the available version. Existing assignments keep the version and materials they received.

Maximum 25 MB per file and 30 MB per save. Save a draft in smaller batches to add more material. Files are stored persistently in the managed database and are accessible only to trainers or the student assigned that exact version. Leave an existing file unchanged unless you select a replacement. Earlier versions retain their files.

Validation errors remain inside the form and retain fields and selected files. A conflicting save from another session is rejected to prevent overwriting. ? opens help without discarding work. Cancel or × closes without saving.
