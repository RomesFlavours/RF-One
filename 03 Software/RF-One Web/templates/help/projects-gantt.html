Gantt

This page shows the plan of one project as a Gantt chart: every chapter and task on a timeline, with its planned period and completion. It is read only; dates and tasks are changed in the project plan.

What you see

Period
From the first planned start to the last planned end of the project, in calendar days. The scale is in weeks, months or quarters depending on how long the project is.
Activity, Responsible, Planned start, Planned end, Planned days, Actual days, %
The same values as in the plan. “after …” lists a task's prerequisites.
Bars
A task bar covers its planned period and is filled up to its completion percentage; a chapter shows a thinner band covering all its tasks. Actual days appear only as a number, because no actual start date is recorded.
⚠
The task starts on or before the planned end date of a prerequisite. It is only a warning: nothing is moved.

Buttons and what happens

▾ next to a chapter or task
Collapses or expands its rows on screen.
Expand all / Collapse all
Opens or closes every chapter and task on screen.
Print
Opens the browser's print window. The print always contains every chapter and task, even the collapsed ones.

None of these buttons changes any data.

Next steps

To change dates, completion or prerequisites, go back to the project plan through the path at the top of the page.
