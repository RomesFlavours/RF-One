Project plan

This page is the plan of one project: its chapters, tasks and subtasks, with dates, responsible people, completion and prerequisites. Here you build and update the plan.

What you can do

  • Create, change and delete chapters.
  • Create tasks inside a chapter and subtasks under a task, change them and delete them.
  • Record completion % and actual days as the work progresses.
  • Open the Gantt and rename the project.

Columns

Activity
Code and title of the chapter or task, with its description. A ⚠ line under a task means it starts on or before the planned end date of one of its prerequisites.
Responsible
The person responsible for the task, from the project's list.
Planned start, Planned end
For a task: its planned start, and start + planned days − 1. For a chapter: the earliest start and latest end of its tasks.
Planned days, Actual days
Planned calendar days, and the actual days entered by hand (— when not entered).
Completion
The completion percentage entered by hand.
Prerequisites
The codes of the tasks that must finish before this one starts; a highlighted code is one that causes a warning. Point at a code to see its title and planned end.

The warning at the top counts the tasks with a prerequisite warning. No date is ever moved automatically.

Buttons and what happens

New chapter
Opens a window with Title (required) and Description. Save adds the chapter at the end of the plan.
New task / + Task
Opens the task window (below); + Task on a chapter row already selects that chapter.
+ Subtask
Opens the task window with the parent task already chosen.
Edit
On a chapter, changes its title and description; on a task, opens the task window with its current values.
Delete
Asks for confirmation, then deletes permanently. It is shown on a chapter only when it has no tasks, and on a task only when it has no subtasks. Deleting a task also removes its prerequisite links.
Gantt
Opens the read-only Gantt chart of this project.
Rename project
Opens a window to change the project name.

The task window

Title, Description
The title is required.
Parent task
Empty for a chapter task; choose a task to make this a subtask. Only one level of subtasks is supported, so a task that has subtasks cannot become a subtask.
Chapter
The chapter of a chapter task. A subtask always belongs to its parent task's chapter.
Existing responsible / Responsible
Choose a name from the project's list, or type a name: a new name is added to the project's list when the task is saved. Leave both empty for no responsible. A dismissed employee cannot receive new tasks.
Planned start date, Planned days
Required; planned days must be at least 1. The window shows the resulting planned end date.
Actual days
Optional: empty, zero or more.
Completion %
Required, from 0 to 100.
Prerequisites
Tick the tasks of this project that must finish before this one starts; use the filter to find them by code or title. A task cannot be its own prerequisite and circular dependencies are refused.

Save stores the task and returns you to its row; Cancel or the × closes the window without saving. If something is refused, the window stays open with what you typed and the reason.
