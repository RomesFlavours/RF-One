Monthly source completeness

One question only: did every bank and card that should have produced an original download this month actually produce one? This is not the accounting close, not reconciliation completion and not P&L approval — a month can be source-complete while every transaction in it is still unclassified. The source of truth is the original monthly download from each issuer; no spreadsheet is ever consulted.

Must be the first day of a month — Bank completeness is monthly, so a date in the middle of one is refused rather than rounded.

Months before this hold imported transactions but are historical: RF-One does not open them, does not demand their missing accounts, and never certifies them complete just because data exists. Months from it onward are opened automatically when an import covers them, and are controlled by the ordinary rules. Setting it for the first time, or moving it earlier, also opens the controlled months covered by files already imported — no file has to be uploaded again. Moving it later changes nothing that already exists — no period, no coverage, no decision an operator has already recorded.
