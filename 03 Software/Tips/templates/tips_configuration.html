Tips Validation Mode

Whether a calculated period needs a person to validate it before it can become final. MANUAL: a person identified through their RF-One login must validate the period; this is the default and applies to any Restaurant that has never set this. AUTOMATIC: a period finalizes itself as soon as Total Tips + Gratuity equals Total Employee Entitlements, with nobody named as having approved it.

This is not the Review Mode above. That one changes what you are shown; this one changes who is accountable for the money.

Current: {{ validation_mode }}
