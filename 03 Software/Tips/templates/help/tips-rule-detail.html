Rule (View / Edit / History)

This page shows one Tip Distribution Rule: its state, every version it has had, and a form to change it. A rule is never rewritten: each change adds a new version, so you can always see which version applied on a given date.

Fields and columns

State / Restaurant / Versions
Whether the rule is ACTIVE (used in calculations) or INACTIVE, the restaurant it belongs to, and how many versions it has.
Version History
Every version, newest first: source role (who gives; Service Owner (Order owner) means the employee who owns the order), recipient role (who receives), calculation base, rate, effective from and to, who created it and when. The version marked current has no end date.
Edit Rule (creates a new version)
The form starts from the current version's values. Change Source Role, Recipient Role, Calculation Base or Rate (%), choose the Effective From (new version) date, and optionally Created by.

Buttons and what happens

Deactivate / Activate
Switches the whole rule off or on immediately; you stay on this page. It can be switched back at any time.
Save New Version
Adds a new version from the chosen date. Existing versions are not modified: the version in force until then ends where the new one starts, and a version planned inside the new version's period is cancelled. A message says exactly which versions were affected. Versions cannot be deleted. If no role exists yet, the form is disabled: add roles first through Manage Roles.

Next steps

Recalculate the affected period in Calculate Tips to see the effect. Saved Periods already saved keep the figures they were saved with.
