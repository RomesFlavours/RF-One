{% if mode is defined and mode == "create" %}This form adds a role to the restaurant, so that Distribution Rules can use it as the role that gives or receives tips.{% else %}This form changes a role already used, or usable, by the Distribution Rules. The change applies wherever the role appears.{% endif %} It does not assign the role to any employee.

Fields

Name
Required. The name shown in the Distribution Rules, for example Server or Host.
Code
Optional short code.
Description
Optional description.
Active
Ticked: the role is active. Untick it to mark the role inactive without deleting it.

Buttons and what happens

{{ "Create Role" if mode is defined and mode == "create" else "Save changes" }}
{% if mode is defined and mode == "create" %}Saves the new role{% else %}Saves the changes{% endif %} and returns to the list of roles. If something is not accepted (for example a missing name), the form stays open with the reason and nothing is saved. Roles cannot be deleted from Tips.

Next steps
