Roles

This page lists the roles of the restaurant (for example Server or Host) that Distribution Rules can use, both as the role that gives tips and as the role that receives them. It only defines the roles: it does not assign a role to any employee.

Fields and columns

Name
The role's name, as it appears in the Distribution Rules.
Code / Description
Optional short code and description.
Active
ACTIVE or INACTIVE.

Buttons and what happens

Edit
Opens the role to change its name, code, description or active state.
New Role
Opens the form to add a role.

Next steps

Once the roles exist, go back to Configuration to describe or create the Distribution Rules that use them.
