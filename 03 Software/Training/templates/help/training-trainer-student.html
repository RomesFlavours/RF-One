This page is one student's training file: their training needs, the pills assigned to each need with their progress, and every quiz attempt. Here you add needs, assign pills and reset the student's password.

What you can do

  • Set a new password for the student.
  • Add a training need.
  • Assign one or more pills to a need.
  • Open any final-quiz or whole-path quiz attempt to see the student's answers.

Fields and columns

Username
The name the student signs in with. When the student is linked to a person in RF-One, that person's name is shown at the top.
Add a training need: Need, Origin
A short description of what the student needs to learn and, optionally, where the need came from (Selection, Observation, Sales, Other).
Training needs
One box per need, listing its pills. Status: Not started (the student never opened it), In progress (opened, final quiz not yet taken), Completed (final quiz taken at least once, whatever the score; it is not a certificate of competence). Attempts lists each final-quiz attempt with date and score; click one to see the answers.
Whole-path quiz history
The student's whole-path quiz attempts with date and score; click a date to see that attempt.

Buttons and what happens

Set a new password · Set new password
Replaces the student's password immediately and lifts any sign-in lockout. The previous password cannot be recovered. Give the new one to the student directly.
Add need
Saves the need; it appears at once on the student's own Training page. It is refused for a dismissed employee.
Assign pills
Opens a window for that need. Narrow the list with Area (the menu section) and Search title; tick the pills to assign. Select all filtered ticks every pill currently listed, Clear selection unticks them all; ticks made under another filter are kept, and the counter shows how many are selected. Pills already assigned to this need are shown ticked and greyed out. Assign selected assigns all selected pills in one step; the message says how many were assigned and how many were already there. Cancel, or the Escape key, closes the window without assigning anything. Assigned pills cannot be removed from this page.
