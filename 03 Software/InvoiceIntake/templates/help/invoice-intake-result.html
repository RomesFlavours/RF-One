Upload result

This page tells you what happened to the file you just uploaded (or to a reading you retried): which documents were saved and in which state, or why the reading failed.

What you may see

Salvato ✓
The file was read and every invoice found in it has been saved. If the file contained several invoices, each one is listed as a separate document.
File già acquisito
Exactly the same file had already been read: nothing new was created, and the documents created the first time are listed.
Lettura non riuscita — nessuna fattura creata
The file could not be read (for example the reading service could not be reached, the file is unreadable, or a page was not processed). The message explains why. No invoice was created; the original file is kept.

Fields and columns

PurchaseDocumentId
The number of the saved document, as shown in Human Review and in the list of all documents.
Stato
NORMALIZED: the document was read completely and its amounts add up, so it is accepted automatically. HUMAN (“richiede verifica umana”): a person must check it in Human Review.

Buttons and what happens

Riprova la lettura
Shown only when the reading failed. Reads the kept original again, on the same record; invoices already saved from this file are never saved twice. You come back to this page with the new outcome.
Apri in Human Review
Opens the document with the original and the data read. It requires reviewer identification; without it access is refused.
Carica un'altra fattura
Back to the upload page. Nothing is undone.

Next steps

Check every HUMAN document in Purchased Human Review. A NORMALIZED document needs no action and stays consultable in the list of all documents. Saving cannot be undone from these pages.
