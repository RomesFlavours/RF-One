How Invoice Intake works

Invoice Intake turns the invoices your suppliers send you into purchase records RF-One can use. You upload a photo or PDF of an invoice (or it arrives by e-mail); the app reads it, saves every invoice it finds as a purchase document, and decides whether it can be trusted automatically or needs a person to check it.

How it works

  • Reading. A PDF with usable digital text is read directly from its text. Photos, scans and PDFs whose text cannot be used are read by an external document-reading service (AWS Textract). Without access to that service photos and scans cannot be read: the file is kept, marked as failed, and can be tried again later. No invoice is ever created from a failed reading.
  • One file, one or more invoices. If a file contains several invoices, each one is saved as its own document. When the boundary between invoices is not clear, the whole file stays one document and goes to review.
  • Same file twice. Uploading exactly the same file again does not create new invoices: the documents already created for it are shown. An invoice already registered with the same supplier, number, date and total is not registered a second time.
  • NORMALIZED or HUMAN. Every saved document gets one of two states. NORMALIZED: supplier, date, total and lines were read and the amounts add up to the cent. HUMAN: something is missing, does not add up, is unreadable or conflicting, and a person must check it in Human Review. Photos and scans almost always end up HUMAN.
  • Corrections never overwrite. In Human Review a correction is stored next to what was read; the original reading is always kept.

Typical flow

  1. On this page choose the invoice file and press Carica e leggi.
  2. Read the result page: the documents created and their state, or the reading error with a button to try again.
  3. Identify yourself as a reviewer (name and role) to open the review pages.
  4. In Purchased Human Review open each HUMAN document, compare it with the original, confirm or correct the fields and add any missing line.
  5. Press Completa review: the document is checked again and becomes NORMALIZED when nothing blocking remains.

What this page shows

Immagine o PDF della fattura
The file to upload: JPG, JPEG, PNG, PDF, WEBP, BMP or TIFF. One file at a time; an invoice split over several files cannot be joined into one invoice here.
Carica e leggi
Keeps a copy of the original file and reads it straight away. The documents found are saved immediately; there is no confirmation step before saving and no undo on these pages. Any correction is made afterwards in Human Review.

Limitations to know

Reviewer identification is not a real login: it records the name and role you declare (VIEWER, REVIEWER or VALIDATOR), for the audit trail and for what you may do on the review pages. The app is meant for one person at a time.
