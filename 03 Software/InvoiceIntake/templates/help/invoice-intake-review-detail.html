Document review

One purchase document: where it came from, what was read from it, what has been corrected and why it is still HUMAN (to be checked) or already NORMALIZED. {% if can_correct is defined and can_correct %}Here you compare it with the original, confirm or correct each value, add missing lines and complete the review.{% else %}With your role you can consult it; confirming and correcting requires the REVIEWER or VALIDATOR role.{% endif %}

Sections of the page

Allegato multi-fattura
Shown when the same file produced several documents: the pages of this invoice and links to the others. The state of the other documents is not shown in this table; open them to see it.
A. Source / Provenance
File name and pages, supplier name as written on the document, how it was read, the e-mail it came with (when received by e-mail) and the canonical supplier with its known alternative names. Apri documento sorgente opens the original file in a new tab.
B. Extracted header
Supplier, number, date and total: Valore estratto is what was read, Valore effettivo is the value in use after the latest review.
B2. Importi del documento e dati di lettura
Total, subtotal, tax, discount, shipping, amount paid and balance due, each with page, label read and confidence when available; other surcharges, conflicting readings and unreadable values. Older documents may have no reading data. The invoice total is corrected in section B.
C. Lines
Each line with its origin (read from the document, with page and text, or added by hand), its values in use, the share of fees and charges allocated to it (Alloc. non-goods), its resulting amount (Effective amount) and its state.
D. Validation reasons
What still prevents the document from being accepted.
Audit / history
Every review action: when, who, which field, the outcome, the previous value and the corrected one. Lines added by hand are listed separately.

Confirming and correcting a value

Each row of sections B, B2 and C has a Correggi column: choose an outcome, type the right value when needed, press Salva.

CORRECT
The value read is right; any text typed is ignored.
INCORRECT
The value read is wrong; a corrected value is mandatory, otherwise an error is shown and nothing is saved.
UNREAD / AMBIGUOUS
The value could not be read, or is unclear. Without a corrected value, a supplier, date or total marked this way keeps the document HUMAN.
Salva
Saves the review of that one value at once, with your name and the time. The original reading is never overwritten; a later review of the same value replaces it in use, and all reviews stay in the history. The document state does not change until you complete the review.

Aggiungi riga mancante

Use it when the document clearly shows a line that was not read. Choose the type (Prodotto, Supplemento, Sconto), write the description as on the document (required) and, if known, normalized item, quantity, unit, unit price and amount; press Aggiungi riga. The line is added alongside the lines read, recorded with your name, and shares in the allocation of fees like the others. Pressing it twice with the same data does not add a duplicate. There is no button to remove an added line.

Completa review → ricalcola NORMALIZED/HUMAN

Checks the document again with the values in use, applying the same rules as when it was saved: supplier, date and total present, lines present, line amounts consistent, totals that add up to the cent, no unreviewed conflicting or unreadable value. A result page then shows either NORMALIZED (all blocking points resolved) or that it stays HUMAN, with the reasons still open, and links back to the document or the queue. Each completed review is also counted in the supplier's format training. If you corrected the supplier name, the name originally read is kept as a known alternative name of that supplier.
