Acquisizioni

One row for every file that reached Invoice Intake, uploaded by hand or received by e-mail, with the outcome of its reading. Use it to find files that could not be read and to try them again. Files with identical content share the same row.

Fields and columns

#
Number of the acquisition.
File
Original name of the file.
Canale
How the file arrived: MANUAL_UPLOAD (uploaded on the Invoice Intake page) or MAILBOX (e-mail attachment).
Stato
RECEIVED: original kept, not read yet. FAILED: reading failed, no invoice created, original kept. ACQUIRED: every invoice found in the file has been saved as a document.
Tentativi
How many times the file has been read.
Lettura
How it was read: PDF-Text (from the PDF's digital text) or Textract-AnalyzeExpense (photos and scans, read by the external reading service).
Pagine
The pages read, followed by the total number of pages in the file.
Documenti
The documents created from this file. Each link opens the document in Human Review, which requires reviewer identification.
Errore
The last reading error, if any.

Buttons and what happens

Riprova
Shown only on FAILED rows. Reads the kept original again, on the same row, and shows the result page. Invoices already saved from this file are never saved twice; nothing else changes.

Next steps

If a retry still fails because the reading service cannot be reached, try again later. Documents created from a file are checked in Purchased Human Review.
