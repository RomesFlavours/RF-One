In-Person Interview

This page guides the Selezionatore through the In-Person Interview and practical assessment of one Application: the planned Assessment Items, the record of each response or observation, and the Consistency Threads that compare what the candidate said at different moments. It produces no score and no hiring decision; you decide how long the interview lasts.

Buttons and what happens

Refresh plan (new evidence)
Updates the planned items with the current configuration and evidence; items already recorded are kept.
Start Interview
Shown while NOT STARTED; marks the interview as in progress.
Selezionatore notes → Save notes
Saves free notes on the interview, replacing the previous notes text.
Record response → Save response
For each item: the status (DONE, PARTIAL, UNRESOLVED, SKIPPED), the raw response or observation exactly as it happened (never rewritten), your separate interpretation note and an optional confidence. Once its status is no longer NOT DONE, the item moves from "Remaining Assessment Items" to "Completed / History". Items still not done, partial or unresolved are listed under "Unresolved / Incomplete Items" so nothing important disappears.
Suggest a follow-up item → Add follow-up
Adds your own follow-up question to the plan.
Record this response as Fit Assessment evidence / as Selection Signal evidence
Shown when the item has a response and is linked to a requirement or Signal: adds the response as evidence (supports, contradicts or neutral; fact, derived information or inference; with a confidence).
Save interview status
Records only the interview's own status (for example COMPLETED or STOPPED EARLY). It never applies an Outcome or a hiring decision.

Consistency

A Consistency Thread follows one topic (for example "Reason for leaving") across the CV/Application, earlier Applications, the Phone Interview and this interview. A difference is something to clarify, never proof of dishonesty.

Consistency Items to Verify
The most important threads still open. Generate clarification question adds to this plan a consistency-check item that quotes the original statements word for word, so you can ask the candidate about them.
Generate cross-Application Consistency Threads
Creates threads comparing this Application with the same person's earlier Applications.
Add a statement → Add statement
Adds a statement to a thread with its source stage, in the exact wording.
Set comparison status → Save status
Records the comparison result (for example CONSISTENT, MINOR VARIATION, MATERIAL INCONSISTENCY, UNRESOLVED, EXPLAINED DIFFERENCE, NEW INFORMATION), a plain factual explanation and, optionally, your resolution.
Create a Consistency Thread → Create thread
Starts a new thread on a topic (suggestions are offered) with an importance.
