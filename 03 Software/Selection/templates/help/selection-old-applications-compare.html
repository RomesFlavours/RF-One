Compare applications

Shows 2 to 4 applications for the same target role side by side, with the facts and the existing indicators of each. Nothing is added: no overall score, no ordering and no suggestion of whom to choose. The decision stays with you.

Rows

Column headings
Each candidate's name, application number and target role. A badge warns when two columns belong to the same person.
Open
Links to the application (where you add notes and update stage and outcome), to the candidate's page and to the original CV in a new tab, when the file is available.
Stage · outcome
Where each application currently stands.
Direct experience, Propedeutic experience, Stability, Career progression
The existing indicators; each can be opened to see how it was calculated. "to be clarified" is never zero.
Work history
The experiences read from each CV with dates, months and category; "Reading uncertain — verify" asks you to check the original.
Declared coordination responsibilities
What each CV says about coordinating other people, quoted as written. It is not a measure of leadership quality; "Not documented in the CV" only means the CV does not mention it.
Missing or uncertain information, Questions to explore
What is still to clarify for each candidate and the questions to ask about it.

When the comparison cannot open

Fewer than 2 or more than 4 applications, different target roles, or an application without a target role: the page shows the reason instead of the table. Go back and change your selection.
