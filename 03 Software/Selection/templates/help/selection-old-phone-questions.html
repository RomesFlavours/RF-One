Phone Interview Questions

This page holds the restaurant's own Phone Interview script. Core Questions are put into every Phone Interview plan for the matching role; Courtesy Questions are short, professional closing questions used only when the Selezionatore ends an interview early through the Escape Route. The first time the page opens, RF-One adds a starter set of questions.

How the questions are used

  • When a Phone Interview plan is created for an Application, it takes the active Core Questions for that role (or for every role), plus questions generated from that Application's Fit Assessment and Signals.
  • Sine Qua Non (gate) questions are always presented first, then the others by importance: CRITICAL, HIGH, MEDIUM, LOW.
  • Changes here apply to plans created or refreshed afterwards; questions already asked in an interview are never changed.

Fields and columns

Question text
The question as the Selezionatore asks it. Required.
Target role (leave blank to apply to every role)
Limits the question to one role (for example SERVER).
Objective — what is this question trying to understand?
Shown to the Selezionatore during the interview.
Importance
CRITICAL, HIGH, MEDIUM or LOW; sets the order within the plan.
Applicable assessment stage(s)
Where the question applies; PHONE INTERVIEW is ticked by default, and is used if you tick nothing.
Sine Qua Non (Gate Question — presented first)
An essential condition. During the interview the Selezionatore records whether the gate passed; a failed gate never stops the Application automatically.
Mandatory within selection process
Marks the question as one that must be covered at some point of the process.
Courtesy Question (Escape Route only)
Moves the question to the Courtesy list: it is used only for a professional closing, up to 3 at a time. Without any Courtesy Question, a generic professional closing is used.
Follow-up guidance (optional)
Hints for follow-up questions.

Buttons and what happens

Create Question
Saves the question as active (as a Courtesy Question if that box is ticked).
Edit this Core Question → Save Core Question
Saves all fields as shown and increases the version. Courtesy Questions have no edit form on this page.
Deactivate / Reactivate
Stops or resumes using the question in new or refreshed plans; it stays in the list.
