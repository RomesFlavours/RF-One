Applications

The review queue of every application. It helps you decide where to look first and pick applications to compare. Review Priority is a starting point, never a ranking and never an automatic discard: lower-priority applications stay fully available.

Filter & sort

No filter is preselected. Filters combine with each other; Results shows how many applications match.

Review Priority, Workflow status, Target role, Stage, Outcome
Show only the applications with that value ("No outcome yet" for those without an outcome).
Sort by
Application date (default), Review Priority, Workflow status or Target role.
Repeated applicants only
Only people who applied before.
Direct experience / Propedeutic experience (months)
Minimum and maximum months. A documented zero counts as 0; unknown months never match unless you tick Include data to be clarified.
Stability
Tick one or more categories; unknown stability matches only with "Include data to be clarified".
Declared coordination
At least one declared responsibility, none documented in the CV, or a specific kind.
Missing or uncertain information
Applications with missing information, uncertain résumé readings, or either.

Review Queue columns

Review Priority
The priority with its main reasons; a second badge shows when it was confirmed or changed by a person.
Workflow
NEW, IN REVIEW, ADVANCE TO PHONE, HOLD or STOP. Set only by a person; Review Priority never changes it.
Stage, Outcome, Direct exp., Propedeutic exp., Stability, Declared coordination, Missing / uncertain
The current state and the main figures read from the résumé. "to be clarified" is never zero; "not documented" means the CV does not mention it.
History, CV
How many earlier applications the person has, and a link to the original CV when the file is available.

Buttons and what happens

Apply / Clear all filters
Applies the filters, or returns to the full, unfiltered list.
Compare selected
Tick 2 to 4 applications of the same target role in the Compare column, then choose this to see them side by side. Otherwise a message explains why the comparison cannot open.
Candidate name / Review →
Opens the application to review it.
