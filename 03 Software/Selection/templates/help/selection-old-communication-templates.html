Communication Templates

A Communication Template is the standard SMS and/or e-mail RF-One sends to a candidate automatically when something happens in the selection process: an Outcome is applied (for example a stop after Primary Screening, a hold or stop after a Phone or In-Person interview, Hirable), the Application advances to the next stage, an interview appointment is confirmed, a reminder is due, or a missing-information questionnaire is sent. The Selezionatore does not rewrite the message for each candidate.

How the right template is chosen

  • For an Outcome, RF-One uses an active template that names that exact Outcome and the Stage the Application is in at that moment. If none exists, no message is sent.
  • For a stage advance, reminder, confirmation or questionnaire, RF-One uses an active template with that trigger event, matching the Stage and role (a blank field matches any). When several match, the most specific one wins.
  • When equally specific templates exist in several languages, the English ("en") one is used: candidates have no recorded language preference yet.
  • The automatic sending does not know the branch: a template limited to a Branch/location is never chosen in this version, so leave that field blank.

Fields and columns

Card title and badges
The purpose (or the trigger event), the trigger event, the Stage, the Outcome and role it is limited to, INACTIVE when switched off, and the version and language (for example "v2 · en").
Trigger event
What makes the message go out.
Stage this applies at
The Application's Stage (APPLICATION RECEIVED, PRIMARY SCREENING, PHONE INTERVIEW, IN PERSON PRACTICAL) when the event happens; "(any)" matches every Stage.
Outcome this answers
Required for Outcome-triggered events; leave "(none …)" for stage-advance, reminder and confirmation events.
Role / Branch/location
Limits the template to one role (for example SERVER). Blank means any. See the branch limitation above.
Purpose / label
Your own name for the template (for example "Rejection after CV Review").
Language
Language code of the text, "en" by default.
SMS text / Email subject / Email body
The message. You can insert $candidate_name, $role, $restaurant_name and, where a scheduling link applies, $scheduling_link; they are replaced when the message is sent. The SMS goes out only if the candidate has a phone number and SMS text exists; the e-mail only if there is an e-mail address and a subject or body.

Buttons and what happens

Create Template
Saves a new active template (version 1). It is used from the next matching event onwards.
Edit content (bumps version — sent history is unaffected) → Save new version
Changes the purpose and texts and increases the version. Messages already sent keep exactly the text they were sent with. Trigger, Stage, Outcome, role and language cannot be changed here: create a new template instead.
Deactivate / Reactivate
Stops or resumes using the template for future messages. Nothing already sent changes.

Current limitation

In this version no real SMS or e-mail delivery service is connected to these templates: each message is prepared and recorded in the Application's Communication History as sent, but it does not actually reach the candidate.
