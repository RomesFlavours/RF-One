Channels

A Channel is a place where the restaurant publishes its job postings (for example Indeed, Facebook or the company website). This page lists the configured Channels and lets you add new ones. The first time the page opens, RF-One adds a few common example Channels; they are examples, not a fixed list.

What you can do

  • See every configured Channel and how it is described.
  • Add a new Channel, describing what it supports and which Acquisition Source its Applications should receive.

Fields and columns

Connected / Manual
Whether the Channel is described as connected to an external service or handled by hand. In this version RF-One does not publish to any external site by itself: this is only a description, and publishing is always done by a person.
Paid / Organic
Whether publishing on this Channel costs money.
Supports metrics / Supports cost tracking
Whether results and costs are expected to be recorded for this Channel. Cost figures appear on Channel Analytics only where a cost was actually recorded.
Default Acquisition Source for Applications arriving through this Channel
The source automatically given to an Application submitted through this Channel's public application form. Choose "(none)" to leave it unset.
INACTIVE
Shown on a Channel that is no longer in use.

Buttons and what happens

Add Channel
Saves the Channel immediately with the options you ticked. If the name is empty, nothing is saved. This page has no button to edit, deactivate or delete a Channel afterwards.

Next steps

A Channel is used when you publish a Job Posting from its page (opened from a Selection Session). Results per Channel and placement then appear on Channel Analytics.
