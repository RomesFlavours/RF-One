Requirement Set

This page manages one Requirement Set: its details, its snapshots and its requirements. A requirement is one thing the restaurant looks for in the role (for example "Works effectively as part of a team"), with how important it is, whether it can be trained, and how evidence for it should be read.

Fields and columns

Requirement Set / Target Role / Version / Status
The set's name, role, current version (it increases with every change to the set or its requirements) and whether it is ACTIVE.
Source template
The template it was created from, or "(built from scratch)". Editing the set never changes the template.
Criticality
MUST HAVE (necessary for the role), PREFERRED (valuable but not mandatory), OPTIONAL (positive, not decisive) or DISQUALIFIER (evidence of it may make a candidate unsuitable).
Trainability
TRAINABLE, PARTIALLY TRAINABLE, NOT TRAINABLE or UNKNOWN.
Category
Free text; suggestions such as "Teamwork" are offered while typing.
Assessment stage(s)
Where the requirement can be judged: RESUME, PHONE INTERVIEW, IN PERSON INTERVIEW, PRACTICAL ASSESSMENT, REFERENCE CHECK, OTHER. Requirements assessable at PHONE INTERVIEW can generate questions in the Phone Interview plan.
Positive / Contrary / Insufficient evidence example, Guidance notes
Examples and notes for the people assessing candidates.

Buttons and what happens

Deactivate this Requirement Set / Reactivate this Requirement Set
Switches the whole set off or on; its content is kept and the version does not change.
Edit Requirement Set details → Save changes
Saves name, target role, location and description, and increases the version. The name is required.
Create snapshot of current state (v…)
Stores a permanent, read-only copy of the set as it is now. Clicking again without changing anything reuses the same snapshot. Fit Assessments are bound to a snapshot, so later edits never change an assessment already made.
View (read-only)
Opens a snapshot.
Deactivate / Reactivate (requirement)
Stops or resumes using that requirement; it stays in the list.
Edit this requirement → Save requirement
Saves the changes and increases the set's version. Snapshots already taken are not affected.
Add requirement
Adds a requirement. Name, criticality, trainability and at least one assessment stage are needed: if no stage is ticked, nothing is saved.

Next steps

After changing requirements, create a new snapshot so new Fit Assessments use the updated version. Use the set in a Selection Session's Rule Set.
