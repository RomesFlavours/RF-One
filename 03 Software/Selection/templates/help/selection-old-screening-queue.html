Primary Screening

This is the work queue of the first screening: every screened Application, ordered so the Selezionatore can concentrate first on the most promising ones. The order is an internal working aid, never a ranking of people, and there is no fixed cut-off: work from the top.

What you can do

  • Choose how many Applications to show.
  • Screen every Application that has not been screened yet, in one go.
  • Open an Application's screening, its full Application page or its original CV.
  • See follow-up reminders that have become due, and the Applications stopped by a Hard Disqualifier.

Fields and columns

Show
First 10, 20 (default), 50 or All Applications of the normal pool.
Reminders Due
Shown when an Application put on hold has reached its follow-up date: candidate, due date and note. RF-One never acts on these by itself. Review → opens the Application's decision page.
Normal Pool
Screened Applications without an active Hard Disqualifier, in working order. Badges show a Repeat applicant (with the number of earlier Applications), how many Criteria are unresolved (insufficient evidence), and any Flag carried by the person from a previous Application.
Findings / Explanation
A short explanation of the screening result.
CV ↗
Opens the original CV in a new tab, when it is available.
Hard Disqualifier Pool
Applications that reached a Hard Disqualifier, with its name. They are never deleted and remain reviewable; they return to the normal pool only when a Selezionatore overrides the Hard Disqualifier.

Buttons and what happens

Run Primary Screening for all un-screened Applications
Screens every Application of the restaurant that has no screening yet, against the active Screening Criteria. Criteria linked to a Signal are evaluated from it; the others are proposed by RF-One's AI assistant from the evidence already present, when the AI service is available, otherwise they stay unresolved. Applications already screened are not touched. This can take a while with many Applications.
Screen / Review / Override
Opens the screening of that Application, where levels can be checked, entered or overridden.
Application
Opens the full Application page.

Next steps

Open the Applications at the top of the Normal Pool, check the proposed levels and resolve the unresolved ones, then move the Application on from its Application pages.
