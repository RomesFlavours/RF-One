Fit Assessment

Organizes the available evidence about one candidate against each requirement of a requirement set. It is never a hiring decision and never a score: the summary only counts requirements by status.

Fields and sections

Candidate, Requirement Set Snapshot, Version assessed, Current stage
The assessment always uses the exact version of the requirement set it was created with, even if the live set changes later. "View live Requirement Set" opens the current set.
Summary
How many requirements are in each status.
Requirement Assessments
For each requirement: its effective status (and what the system said, if a person changed it), "Why this matters / evaluation guidance" from the requirement's configuration, the evidence items with source, classification, relationship, confidence and explanation, and any note.

Buttons and what happens

Refresh résumé-stage assessment
Re-runs the automatic résumé evidence against the same version. Evidence added by a person and any confirmation or override are left untouched.
Save note (assessment)
Under "Add / edit assessment note": a note for your own reference. It is not evidence.
Confirm current status
Confirms the system's status for that requirement.
Add evidence
Adds an evidence item: source type and stage, text, classification, relationship to the requirement, confidence, optional source reference and explanation. It is marked as added by a person.
Override / Save note (requirement)
Under "Override status / add note": sets a different effective status with the reason, or saves a note that is not evidence. The system's own status stays visible.
← Back to candidate
Returns to the candidate page.
