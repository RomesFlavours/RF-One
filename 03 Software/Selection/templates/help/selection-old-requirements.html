Requirement Sets

A Requirement Set describes what the restaurant is looking for in one hiring need (for example "Server - Mount Dora"): a list of requirements, each with its criticality, trainability and the stages at which it can be assessed. It does not evaluate any candidate by itself; Fit Assessments compare candidates against it. This page lists the restaurant's Requirement Sets and lets you create new ones.

What you can do

  • See every Requirement Set and open one to manage its requirements.
  • Create a Requirement Set from a ready-made template, or from scratch.

Fields and columns

Client / Requirement Sets / Templates available
The restaurant, how many sets it has, and how many templates can be used as a starting point.
Name / Target Role / Location
How the set is identified.
Requirements
Active requirements out of the total.
Version
Increases every time the set or one of its requirements changes.
Status
ACTIVE or INACTIVE.
Source Template
The template the set was created from, or "(custom)".

Buttons and what happens

Click a row or its name
Opens the Requirement Set.
Use this template
Creates a new Requirement Set for this restaurant with a copy of the template's requirements, using the name, target role and location you entered, and opens it. The copy belongs to the restaurant: later edits never change the template. A name is required.
Create empty Requirement Set
Creates a set with no requirements and opens it so you can add them. A name is required.

Next steps

Open the set, add or adjust its requirements, then create a snapshot. Select the set in a Selection Session's Rule Set to use it for that hiring need.
