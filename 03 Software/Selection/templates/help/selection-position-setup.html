1 · Position

Defines what this position needs and what candidates will see: the requirements used to evaluate applications, the English job ad, the number of openings and the standard interview questions. Approving this step opens the application page.

The top of the position page

  • Under the title: role, location, number of openings, manager and status (Pending approval, Open or Closed).
  • Application page ↗ (after the first approval) opens the public page candidates use, in a new tab.
  • The banner There are unapproved changes means you edited requirements, job ad or questions after the last approval: candidates and the evaluation still use the approved version until you approve again.
  • The tabs lead to the other steps of the same position; each has its own help.

Fields and sections

What you need (manager's description)
The description written when the position was created.
AI draft (pending approval)
Appears when AI has proposed requirements, a number of openings and a job ad. Tick what you want to keep; items marked "Still to decide" are open questions AI did not invent answers for.
Requirements
What the job needs. Each one has a Type (Must-have, Preferred, Optional, Condition to verify), an Area and whether it is Trainable?. Must-have requirements decide the proposal groups. Résumés are matched against the name and the description, so write the English words that appear in résumés (for example "server, waiter, table service"). Use only job-related requirements.
Number of openings
How many people you want to hire; used to show "Hired / openings".
English job ad (published on the application page)
The text candidates read before applying. Text in square brackets is treated as an unfinished placeholder.
Standard interview questions
One per line, in English, up to six (any extra lines are dropped). Candidates answer them in the online interview. {% if ai_policy.allows("cv_questions") %}AI adds up to three more questions based on each candidate's résumé.{% else %}Résumé-based AI questions are not active for this position.{% endif %} "Other standard questions already available in Selection" lists questions you can copy.

Buttons and what happens

Use selected items / Discard (AI draft)
Use selected items adds the ticked requirements and, if ticked, replaces the job ad and the number of openings. Discard drops the draft. Either way the changes still need approval.
Edit → Save / Remove
Changes a requirement, or removes it from the position. Both take effect for candidates only after approval.
+ Add requirement → Add
Adds a new requirement with its name, description and keywords, type, area and trainability.
+ Copy from an existing Selection template → Copy
Adds the requirements of a ready-made template to this position; you can then edit or remove them.
{% if ai_policy.allows("position_drafting") %}
+ Request a new AI draft → Draft
Asks AI for a new proposal, optionally with extra details. The result appears at the top of this step for you to choose from.
{% endif %}
Save (job ad, openings and questions)
Saves the job ad, the number of openings and the questions. They become effective only after approval.
Approve and open position / Approve changes
Makes the current requirements, job ad and questions the approved version. The first approval opens the application page and moves the position to Open positions. Approval is refused while there is no requirement, no job ad text, no standard question, or placeholders in square brackets are left in the ad; a warning appears if no requirement is Must-have. Existing applications are evaluated again against the new approved version.
