Job Posting

The job posting of a Selection Session: its base text, the versions of that text adapted to each channel, and the places where you published it, each with its own tracking link. Selection Old does not publish anything by itself: you place the text on the channel and record it here.

Fields and sections

Role, Branch/Location, Current version, status
What the posting is for, its latest version and whether it is approved.
Base Posting Content
The public text in separate parts: title, company/brand and branch descriptions (independent of each other), role summary, responsibilities, minimum and preferred requirements, availability, schedule, compensation and benefits (descriptive text only, never used as selection rules), location, application instructions and other information.
Version history
Every saved version with its source, author, reason and approver. Earlier versions are never overwritten.
Channel Variants
Available once the base posting is approved: the text adapted for one channel, with its status and version.
Publications / Tracking Links
Each recorded placement with channel, placement, status, cost and its tracking link. Applications that arrive through a tracking link are attributed to that placement.

Buttons and what happens

Save as new version
Saves the base text as a new version, with your name as author. Once the posting has been approved at least once, a reason is required.
Approve Base Posting
Approves the current version under the name you enter. Approval is required before channel variants can be generated.
Generate Variant
Under "Generate a new channel variant": creates a variant for the chosen channel. Its text must stay consistent in meaning with the approved base posting.
Save new version / Approve this variant
Edits a variant as a new version (a reason is required once it has been approved) and approves it. Each variant is approved on its own; there is no "approve all".
Record Publication + Get Tracking Link
Available for an approved variant: records where you published it (placement label, optional link, cost and currency, notes, who) and creates the tracking link to use in that placement.
← Back to Session
Returns to the Selection Session.
