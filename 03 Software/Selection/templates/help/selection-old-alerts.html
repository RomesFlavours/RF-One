Alerts

This page collects the open alerts raised by messages received from candidates that need a Selezionatore's attention: for example a reply that arrives after an automatic "no response" stop, a request to reschedule, an availability conflict or an ambiguous message.

What you can do

  • Read each open alert and the exact text the candidate sent.
  • Open the Application's communication history to see the whole exchange.
  • Acknowledge an alert once you have seen it.

Fields and columns

Alert title
The reason the message was flagged (for example "Reschedule Request").
Application #
The Application the message belongs to.
Quoted text
The message exactly as received.
Received
When the message arrived.

Buttons and what happens

View Communication History →
Opens the list of every message sent to and received from this candidate. Nothing is changed.
Acknowledge
Records that you (your current acting identity) have seen the alert, removes it from this list and takes you to that Application's Communication History. It does not change the Application's Stage or Outcome: any decision is taken separately, from the Application's own pages. There is no button to bring an acknowledged alert back to this list.

Next steps

After reading the message, open the Application (Dossier or Communication History) and decide what to do, for example reopen it, reschedule or record a new Outcome.
