Acquisition Sources

An Acquisition Source records where a candidate found out about the role (for example Indeed, LinkedIn, a referral or a walk-in). It is separate from the communication channel RF-One later uses to contact the candidate. This page lists the sources configured for the restaurant and lets you add new ones.

What you can do

  • See every configured source, active or not. The first time the page opens, RF-One adds a few common example sources.
  • Add a new source with a name and an optional description.

Fields and columns

Configured Acquisition Sources
Each card shows the source name, its description if any, and an INACTIVE badge when the source is no longer in use.
Name
The label of the source (for example "Referral"). Required.
Description (optional)
A short note explaining when this source applies.

Buttons and what happens

Add Source
Saves the new source immediately and shows it in the list. If the name is empty, nothing is saved.

This version of the page has no button to rename, deactivate or delete a source, even though the note at the top mentions renaming and deactivating: once added, a source stays in the list as it is.

How the source reaches an Application

On the Channels page each Channel can name a default Acquisition Source. An Application submitted through that Channel's public application form receives that source automatically, and the Application's Dossier shows it as "Acquisition Source" ("(unknown)" when none was recorded).

Next steps

Go to Channels to assign the new source as a Channel's default.
