In-Person Interview Sections

This page defines the restaurant's own structure of the In-Person Interview: Sections (for example "Work Personality" or a practical test) and, inside each Section, its Assessment Items (questions, observations, practical tests, role-plays, consistency checks, courtesy prompts). The first time the page opens, RF-One adds a starter structure. Items carried forward from the Phone Interview are generated automatically for each candidate and are not configured here.

How it is used

  • When an In-Person Interview plan is created for an Application, it takes the active Sections for that role (or for every role) and their active Items, ordered by Section order and then by importance.
  • Changes apply to plans created or refreshed afterwards; items already recorded in an interview are not changed.
  • Sections appear in their configured order ("order N" on each card). This page has no control to change that order, despite the note at the top.

Fields and columns

Section: Name / Section kind / Target role / Description
The Section's label, its kind (for example Welcome Observation, Work Personality, Hospitality Motivation, Practical Technical, Commitment, Final Observation, Other), the role it is limited to (blank = every role) and what it covers.
Item: Title / question / Item type
What the Selezionatore asks or observes, and its type: QUESTION, OBSERVATION, PRACTICAL TEST, ROLE PLAY, CONSISTENCY CHECK, CARRY FORWARD, COURTESY.
Instruction to candidate / Scenario
What the candidate is told, and the scenario of a practical test or role-play.
Objective / Importance
What the item tries to understand, and how important it is (it sets the order within the Section).
Mandatory within selection process
Marks an item that must be covered at some point of the process.
Expected / Positive / Contrary / Insufficient evidence guidance
How to read what the candidate says or does.
Selezionatore instructions (what to observe / how to run it)
Shown to the Selezionatore during the interview.

Buttons and what happens

Create Section
Adds an active Section. A name is required.
Edit this Section → Save Section
Saves name, kind, role and description, and increases the version.
Add an Assessment Item to this Section → Add Item
Adds an active item. Title/question and type are required.
Edit this Item → Save Item
Saves all fields of the item as shown.
Deactivate / Reactivate (Section or Item)
Stops or resumes using it in new or refreshed plans; it stays on the page.
