Requirement Set snapshot

A snapshot is a permanent, read-only copy of a Requirement Set exactly as it was at one version. Fit Assessments are made against a snapshot, so this page shows precisely the requirements a candidate was assessed against, whatever has changed in the live set since. Nothing on this page can be edited.

Fields and columns

Snapshot of / Version captured / Target Role / Created
Which set, which version, its role and when the snapshot was taken. The note below also gives the location and whether the set was active at that moment.
Requirements captured
Each requirement as it was: name, criticality, trainability, category, the stages where it could be assessed, its description and the evidence guidance. WAS INACTIVE marks a requirement that was switched off at capture time.
