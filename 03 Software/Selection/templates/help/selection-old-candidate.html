Candidate page

Everything Selection Old read and calculated from one candidate's résumé, kept in separate parts so you can see what is a fact, what is derived and what is only worth asking about. No universal score is computed or shown.

Fields and sections

Candidate, Target Role (application), Status, Parsing
The name, the target role of the candidate's application, the import status and how the résumé was read (REAL AI, RULE-BASED or DEMO / MOCK). With RULE-BASED reading, a field is left blank rather than guessed. When the application has no supported target role (Server or FOH Team Leader), a red box says the target role is to be clarified: no role is assumed and experience is not classified against a target.
Open Original CV ↗
Opens the uploaded file in a new tab. Always compare what Selection read with the source document. If the file can no longer be found, the page says the original is unavailable.
Application link and priority badge
Opens the candidate's application (review priority and selection signals).
Candidate Flags
Strong historical facts from an earlier application of the same person, for example a training check not passed. Never an automatic rejection.
Fit Assessments
Assessments of this candidate against a requirement set. Each row opens its detail.
Source & Extraction Information
Where the résumé came from, the file, when it was imported and which reader was used.
1. Facts
Contact, profiles, languages, availability, summary, skills, education, certifications and the work history as written: title, employer, dates and months per role, with the normalized role. "Reading uncertain — verify" means the grouping of that entry is not certain: check the original. A recognized leadership title is only the declared role; the coordination actually performed is not verified. The raw extracted text is shown at the end.
2. Derived Information
Calculated from the facts, never stated on the résumé: experience breakdown for the target role (target, equivalent, propedeutic, adjacent, other), industry experience, total career span, tenure figures, career trajectory and information quality. Age-related context, when shown, is excluded from all indicators.
Declared coordination responsibilities
Duties the résumé describes as exercised on other people, with the experience, area, number of people (when declared) and the sentence as written. It is what the candidate declares, not a check or a measure of leadership quality; no months are counted from it. Neutral interview questions follow.
3. Flags & Suggested Questions
Things worth asking about, each with its evidence, explanation, attention level and a suggested question. A flag is never automatically negative.
4. Indicators
Separate dimensions, never combined. Each indicator can be opened to see how it was calculated. Months by role are counted from the job titles as declared.

Buttons and what happens

Create Fit Assessment
Choose an active requirement set under "Assess against Requirement Set". A new assessment is created against the current version of that set and organizes the available résumé evidence for each requirement; it is not a decision and not a score. If no active requirement set exists, create one in Requirement Sets first.
← Back to candidate list
Returns to Candidates. This page itself changes nothing else.

Next steps

Open the Fit Assessment to review the evidence per requirement, or open the application to continue the review.
