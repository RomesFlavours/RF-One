Selection Queues

Queues are operational lists used to organise work (for example "Active Review", "Call Later", "Hold", "Reconsider", "Hired", "Closed"). A queue is never a hiring decision: an Application changes queue only when a Selezionatore moves it, or when an Outcome they apply is configured to move it. The first time the page opens, RF-One adds a few example queues.

What you can do

  • See every queue with its order, description and status.
  • Rename a queue, change its description or its display order.
  • Deactivate or reactivate a queue, and create new ones.

Fields and columns

Order
The position of the queue in lists (lower numbers first).
Name / Description
The queue's label and what it means operationally.
Status
ACTIVE or INACTIVE.

Buttons and what happens

Deactivate / Reactivate
Switches the queue off or on. The queue and its history are kept; an inactive queue is shown as "(inactive)" in the Outcome settings.
Edit "…" → Save changes
Saves the new name, description and display order. Leaving the order empty keeps the current one.
Create Queue
Adds a new active queue. If the name is empty, nothing is created.

Next steps

On Selection Outcomes, choose a queue in an Outcome's "move the Application into this operational queue/list" setting, so Applications move there automatically when that Outcome is applied.
