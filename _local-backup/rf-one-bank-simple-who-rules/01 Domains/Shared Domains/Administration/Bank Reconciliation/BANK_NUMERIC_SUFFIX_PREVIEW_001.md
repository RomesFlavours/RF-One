# BANK_NUMERIC_SUFFIX_PREVIEW_001

1. Observed: Save preserved the conversation but Preview stayed disabled because the chat could not express the requested trailing-date/name-number extraction policy. Earlier extractors only supported literal delimiters, final alphanumeric codes, or the entire remainder.
2. Extractor capability: optional suffix_policy supports dates (valid final MM/DD), numbers (standalone numeric/slash tokens), and review_numbers (remove valid dates, retain explicit complete-name exceptions, flag unknown numeric names per row). Interior numbers and mixed alphanumeric tokens stay untouched. Defaults preserve all previous rule behavior. Source highlighting still uses exact original slices.
3. Chat and preview: schema explicitly supports these options and instructs ChatGPT not to repeat answered global questions. Preview remains usable for an incomplete extractor and prepares the current conversation using the expanded schema before previewing. It never silently previews the previous rule or activates a version. Photo policies retain their completeness checks. Saved messages that have not been sent must be sent first.
4. Uncertain row behavior: candidate is highlighted and labeled Check highlighted name; no WHO/WHY/WHOM assignment is proposed. Photo requires a resolved WHO. Known name exceptions such as SEASONS 52 are explicit human examples, not fabricated identifiers. Apply still requires a current signed preview and audited rollback.
5. Validation: four integration checks cover numeric suffixes, saved-incomplete preview preparation, existing Zelle/ACH extraction, nested Photo/application/rollback. Real ChatGPT call with synthetic descriptions returned review_numbers, preserved SEASONS 52, removed 06/30 and withheld unknown numeric identities. Browser renderer verified enabled Preview and all three row cases on sample data. No live rule or financial row is applied by this task.
6. Recovery: user can reopen their saved changes and press Preview without repeating the instruction. File list, code backups and database snapshot are in the deployment output.
