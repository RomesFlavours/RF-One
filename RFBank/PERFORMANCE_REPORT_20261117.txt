4. Implemented changes
- SQLite WHO snapshots use connection-local data_version, own-write total_changes
  and schema_version. A pinned read transaction prevents mixed snapshots. A new
  connection/revision hashes its full snapshot once, allowing unchanged results
  to be shared across pooled connections. Bounds limit memory retention. Pending
  edits/existing transactions bypass the cache. Concurrent unchanged calls share
  one calculation. Returned dictionaries are copied, never shared with callers.
- Text normalization uses a bounded pure-value cache and per-row normalized fields.
- Rule versions and dated card settlement assignments are loaded in bulk. The
  existing canonical settlement resolver still decides historical ownership and
  its legacy fallback, with the same half-open date boundaries.
- Active WHY picker data is read with a targeted catalog join instead of the full
  configuration view and one get() per reason. Provisional exclusions are unchanged.
- WHO search/filter/count/page operations now run on the server. Latest-response
  ordering prevents an earlier search response from replacing a newer one.
- Nested SELECT workspaces index predicate columns and reuse compatible snapshots
  within one Sources execution only. SELECT authorization, allowed functions,
  timeout, no LIMIT/OFFSET hiding and fetchmany(2) ambiguity handling remain.
  Internal errors restore read-only authorization in finally. Fingerprints are
  captured before index pages, preserving the original evidence image.
- Amazon/PayPal projections use batched changed-row inserts/updates and targeted
  obsolete-row deletion. Unchanged projections perform zero row changes. Source
  reads and writes retain SQLite writer serialization without a destructive DELETE.
- One persistent index: ix_ft_posting_date_id(posting_date,id). Existing card and
  rule-version indices were not duplicated. A date range sorted by date/id changes
  from SCAN plus temporary sort to indexed SEARCH. A 200-query isolated probe was
  0.192 s before and 0.037 s after, with identical rows.
