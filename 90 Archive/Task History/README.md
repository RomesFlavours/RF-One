# Task History Archive

## Purpose

This directory holds completed RF-One task specifications and their execution reports, removed from the active `07 Tasks/` workspace once the Product Owner has reviewed and committed their outcome.

## Contents

- `Tasks/` — completed task specifications (e.g. `TASK_CORE_001_...md`).
- `Reports/` — execution reports for completed tasks (e.g. `TASK_CORE_005_REPORT.md`). Not every archived task has a report; only reports that were actually produced are archived here.

## Authority

These files are historical/provenance material, not canonical architecture. They record **why and how** a change was made at the time it was made.

Canonical meaning currently resides in `00 Core/`, `01 Domains/`, `02 Products/`, `03 Software/`, and `09 Strategy/` — never in this archive.

Historical "Approved" status wording inside an archived Task or Report reflected that document's authority at the time it was written. It does not supersede current canonical documentation. Authority is determined by location, not by status text inside a file, consistent with `90 Archive/README.md`.

## Maintenance

Archived files should normally remain unchanged except for explicit archival/governance maintenance (e.g. moving further files into this structure). Path references inside an archived Task or Report that were correct when the document was written are expected to become stale over time; that is a normal property of historical record and is not, by itself, an error to silently fix.
