# Superseded Documents

## Purpose

This directory preserves canonical documents that were **superseded and retired** from an active layer, so their history and provenance remain available. Files are kept **unchanged**, under the same relative path they had in the active layer (e.g. `01 Domains/Shared Domains/...`), so the original location is evident.

Nothing here is current RF-One authority, regardless of any `Approved` or similar status text inside a file (see `90 Archive/README.md`). Relative links inside these files pointed to their original locations and may no longer resolve; that is expected of historical record.
